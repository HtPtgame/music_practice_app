# 🎵 測試音檔說明

## 📁 檔案清單

此資料夾包含用於驗證演奏準確度的測試音檔:

| 檔案名稱 | 類型 | 用途 | 預期準確率 |
|---------|------|------|-----------|
| `測試音檔(midi轉檔).wav` | MIDI → WAV | 100% 準確基準測試 | 95-100% |
| `測試音檔(環境).wav` | 真實錄製 | 真實環境演奏測試 | 85-95% |
| `小星星(環境).wav` | 真實錄製 | 實際曲目演奏測試 | 視演奏品質 |
| `環境背景.wav` | 環境錄音 | 噪音抑制能力測試 | 0% (無音符) |

---

## 🎯 測試目的

### 1. 測試音檔(midi轉檔).wav
**目的**: 建立準確度基準線

- 這是由 MIDI 檔案直接轉換成 WAV 的音檔
- 音高、節奏、時間點都 100% 準確
- 用於驗證頻譜驗證引擎在理想情況下的表現
- **預期結果**: 準確率應達到 95-100%

**如果準確率低於 95%**:
- 檢查 `energyThreshold` 是否設定過高
- 檢查 `timingTolerance` 是否設定過窄
- 檢查 WAV 檔案品質(應為 44100Hz, 16-bit PCM)

---

### 2. 測試音檔(環境).wav
**目的**: 測試真實環境下的準確度

- 在有環境噪音的情況下錄製的真實演奏
- 包含背景噪音、房間混響等真實因素
- 用於驗證系統在實際使用情境下的表現
- **預期結果**: 準確率應達到 85-95%

**如果準確率低於 85%**:
- 可能是環境噪音過大,建議在安靜環境錄製
- 可能是演奏品質需改善(漏音、錯音)
- 考慮調整 `energyThreshold` 以適應環境噪音

---

### 3. 小星星(環境).wav
**目的**: 測試實際曲目的演奏準確度

- 真實的「小星星」曲目演奏錄音
- 用於測試系統對不同曲目的適應性
- 提供實際使用場景的參考數據
- **預期結果**: 視實際演奏品質而定

**注意事項**:
- 需要對應的小星星 MIDI 檔案
- 準確率會反映真實的演奏水準
- 可用於演示系統功能

---

### 4. 環境背景.wav
**目的**: 驗證噪音抑制能力

- 純環境背景音,沒有任何樂器演奏
- 用於測試系統是否會誤報音符
- 驗證 `energyThreshold` 設定是否合適
- **預期結果**: 應該檢測到 0 個正確音符

**如果檢測到音符**:
- 提高 `energyThreshold` 參數(例如 0.15 → 0.20)
- 檢查諧波驗證權重設定
- 確認頻譜分析參數正確

## 📊 檔案規格

所有測試音檔應符合以下規格:

| 參數 | 規格 |
|-----|------|
| **格式** | WAV (RIFF WAVE) |
| **取樣率** | 44100 Hz |
| **位元深度** | 16-bit PCM |
| **聲道** | 單聲道 (Mono) |
| **編碼** | Little-Endian |

### 驗證檔案規格

**使用 PowerShell**:
```powershell
# 查看檔案大小
Get-ChildItem "測試音檔(midi轉檔).wav" | Format-List Name, Length

# 檢查 WAV 標頭
Format-Hex "測試音檔(midi轉檔).wav" -Count 44
```

**應該看到**:
```
00 01        # NumChannels: 1 (Mono)
44 AC 00 00  # SampleRate: 44100 (Little-Endian)
10 00        # BitsPerSample: 16
```

## 🔧 如何製作測試音檔

### 方法 1: MIDI → WAV (基準測試)

**使用 FluidSynth**:
```powershell
fluidsynth -ni assets/TimGM6mb.sf2 assets/測試.mid -F 測試音檔(midi轉檔).wav -r 44100
```

**使用線上工具**:
- [MIDI to MP3 Converter](https://www.conversion-tool.com/midi/)
- 然後用 Audacity 轉換成 WAV (44100Hz, Mono)

### 方法 2: 真實錄製 (環境測試)

**使用 Audacity**:
1. 設定: 44100Hz, Mono
2. 開始錄製
3. 演奏樂器
4. 停止錄製
5. 匯出為 WAV (16-bit PCM)

**使用手機錄音 App**:
1. 設定錄音品質為最高
2. 錄製演奏
3. 傳輸到電腦
4. 用 Audacity 轉換格式

### 方法 3: 背景噪音錄製

**步驟**:
1. 在預定的演奏環境中
2. 不要演奏任何樂器
3. 錄製 30-60 秒的環境音
4. 用於測試噪音抑制能力

## 💡 故障排除

### 問題: 找不到測試檔案

**檢查清單**:
- [ ] 檔案確實存在於 `assets/test_voice/` 資料夾
- [ ] 檔案名稱完全正確(包括括號和空格)
- [ ] 檔案權限正確
- [ ] 路徑使用正確的斜線(`\` for Windows)

### 問題: 準確率異常低

**可能原因**:
1. WAV 檔案格式不正確
2. 參數設定不當
3. 檔案損壞

**解決步驟**:
```powershell
# 1. 驗證檔案格式
Format-Hex "測試音檔(midi轉檔).wav" -Count 44

# 2. 檢查檔案大小(不應該是 0 bytes)
Get-ChildItem "測試音檔(midi轉檔).wav"

# 3. 重新生成測試檔案
# (使用上述 MIDI → WAV 方法)
```

### 問題: 測試崩潰

**錯誤訊息範例**:
```
Unhandled exception:
RangeError (index): Invalid value: Not in inclusive range 0..1023: 1024
```

**可能原因**:
- FFT 大小設定錯誤
- 音訊檔案損壞
- 記憶體不足

**解決方案**:
```powershell
# 清除快取並重新安裝
flutter clean
flutter pub get

# 重新執行測試
dart test_week3.dart 1
```
