# 🎹 即時樂譜比對功能使用指南

## ✅ 初始化成功!

根據日志,即時樂譜比對器已成功初始化:
```
✅✅✅ 即時比對器初始化完成! 音符數: 147
```

## 📱 如何使用即時比對功能

### 步驟 1: 確認調試資訊框
在練習頁面應該可以看到**橙色調試框**:
```
🐛 調試資訊
MIDI檔案: 小星星.mid
比對器狀態: ✅ 已初始化
```

如果看到 "✅ 已初始化",說明一切正常!

### 步驟 2: 打開即時比對開關
在橙色調試框下方,找到 **"即時樂譜比對"** 開關:
```
🎹 即時樂譜比對  [關] → [開]
```

**重要**: 這個開關**默認是關閉的**,需要手動打開!

### 步驟 3: 開始錄音並彈奏
1. 點擊 "開始錄音" 按鈕
2. 倒數結束後開始彈奏鋼琴
3. **即時反饋會在錄音過程中顯示**

### 步驟 4: 查看即時反饋

錄音時應該看到:
- ✅ **進度條**: 顯示已彈奏的音符百分比
- 📊 **準確度**: 即時計算的正確率
- 🎯 **判定結果**: Perfect! (+100), Good! (+80), Wrong (-50), Miss (0)
- 📈 **統計數據**: 
  - Correct: X 個
  - Wrong: X 個
  - Miss: X 個
  - Noise: X 個

## 🐛 調試日志

### 期望看到的日志 (錄音期間)

如果即時比對**正常工作**,應該看到類似:

```
I/flutter: 📊 收到比對結果: Wrong -50

```

### 如果沒有看到這些日志

可能原因:
1. **即時比對開關未打開** ← 最常見!
2. 音頻檢測沒有識別到音符
3. 音符能量太低被過濾掉

## 🔧 故障排除

### 問題 1: 開關不可見
**症狀**: 找不到 "即時樂譜比對" 開關

**解決**: 
- 確認橙色調試框顯示 "✅ 已初始化"
- 如果顯示 "❌ 未初始化",點擊 "🔧 手動初始化" 按鈕

### 問題 2: 開關打開但沒有反饋
**症狀**: 開關是開的,但錄音時沒有即時反饋

**可能原因**:
1. 音頻能量太低 (minEnergy: 0.2)
2. 諧波比率不足 (minHarmonicRatio: 0.4)
3. 持續時間太短 (minDurationFrames: 3)

**檢查方法**:
- 查看日志是否有 "⏸️ 即時比對未啟用,跳過音頻處理"
- 查看日志是否有音符檢測輸出

### 問題 3: 檢測到音符但沒有判定
**症狀**: 有音符檢測日志,但沒有 "📊 收到比對結果"

**可能原因**:
- 檢測到的音符不在目標曲目的範圍內
- 音符順序偏移超過搜尋窗口 (searchWindow: 3)

## ⚙️ 當前配置參數

```dart
RealTimeScoreMatcher(
  targetSong: 147 個音符,
  searchWindow: 3,        // 允許跳過 3 個音符
  minEnergy: 0.2,         // 最小能量閾值
  minDurationFrames: 3,   // 最小持續幀數
  minHarmonicRatio: 0.4,  // 最小諧波比率
  pitchTolerance: 1,      // 音高容差 ±1 半音
)
```
