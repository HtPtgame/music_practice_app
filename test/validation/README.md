# 驗證測試目錄

本目錄包含各個開發階段（Phase）的驗證測試檔案。

## 📁 檔案列表

### `phase1a_alignment_test.dart`
**Phase**: 1A - 自動時間對齊  
**開發日期**: 2025/10/25  
**測試目標**:
- ✅ 驗證自動檢測錄音起始點功能
- ✅ 驗證時間軸對齊功能
- ✅ 確保不影響樂曲中間的休止符

**測試方法**:
- 使用生日快樂.mid + 對應 WAV
- 手動添加不同長度的靜音前綴（0-30秒）
- 驗證能否正確檢測並對齊

**執行方式**:
```bash
dart test/validation/phase1a_alignment_test.dart
```

**預期結果**:
- 能正確檢測 0-30 秒延遲的錄音起始點
- 對齊後的召回率應接近無延遲版本

### `detection_optimized_test.dart`
**Phase**: Phase 0 + 混淆矩陣評估  
**開發日期**: 2025/10/25  
**測試目標**:
- ✅ 驗證混淆矩陣計算正確性
- ✅ 測試「亂彈高分」問題是否被修復
- ✅ 測試錯誤曲目檢測能力
- ✅ 測試雜訊抑制能力

**測試計劃** (4輪):
1. 第一輪: 生日快樂.mid (簡單基準)
2. 第二輪: 測試音檔.mid (單音無伴奏)
3. 第三輪: 小星星.mid (有伴奏)
4. 第四輪: 名偵探柯南.mid (複雜快速)

**執行方式**:
```bash
dart test/validation/detection_optimized_test.dart
```

**驗證標準**:
- Precision ≥ 0.9 (環境噪音測試)
- Recall ≥ 0.8 (正確演奏測試)
- F1 Score 能正確識別亂彈/錯誤曲目

### `comprehensive_detection_test.dart`
**Phase**: 綜合檢測系統驗證  
**開發日期**: 2025/10/25  
**測試範圍**:
- ✅ 正確演奏檢測（應該高召回率）
- ✅ 錯誤音檔排除（應該低召回率）
- ✅ 環境噪音排除（應該極低召回率）

**測試類型**:
1. **正確演奏** (6個音檔)
   - 標準錄音.wav
   - 初學者_高閾值.wav
   - 中等_中閾值.wav
   - 專業_低閾值.wav
   - 完美演奏.wav
   - 有伴奏.wav

2. **環境噪音** (4個音檔)
   - 環境噪音_高閾值.wav
   - 環境噪音_中閾值.wav
   - 環境噪音_低閾值.wav
   - 靜音.wav

3. **錯誤曲目** (2個音檔)
   - 錯誤曲目1.wav
   - 錯誤曲目2.wav

**執行方式**:
```bash
dart test/validation/comprehensive_detection_test.dart
```

**總結指標**:
- 正確演奏平均召回率
- 環境噪音平均召回率
- 錯誤曲目檢測率

## 🚨 已知限制

### 需要改進的問題

1. **錯誤曲目檢測**
   - 問題: 完全不同的曲目仍有 15.8% 召回率
   - 影響: 可能誤導使用者
   - 優先級: 🔴 高

2. **極快音符檢測**
   - 問題: 柯南主題曲等快速曲目召回率偏低
   - 影響: 使用者體驗下降
   - 優先級: 🟡 中
   - 狀態: ✅ Round 10 已改善

3. **伴奏干擾**
   - 問題: 複雜伴奏可能產生誤報
   - 影響: Precision 輕微下降
   - 優先級: 🟢 低
